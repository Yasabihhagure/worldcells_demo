# worldcells デモ

地図生成ライブラリ **worldcells** のブラウザデモです。平面・円筒・球の地図を、シードと大きさを決めてその場で生成し、3D で表示します。

- デモ：<https://yasabihhagure.github.io/worldcells_demo/>
- 例（球・ヘクス、シード 12345）：<https://yasabihhagure.github.io/worldcells_demo/?combo=4&seed=12345&m=18&scale=10>

## デモでできること

- 形 5 通りの切り替え（平面・矩形／平面・ヘクス／円筒・矩形／円筒・ヘクス／球・ヘクス）
- シードの指定（ランダムも）、大きさの指定、標高の倍率、円筒の巻き表示
- セルをクリックして情報を見る、バイオームの凡例
- 地図を JSON で書き出す（ダウンロード）
- 書き出した JSON を読み込んで表示する（ボタンか、画面へのドラッグ＆ドロップ）。手で書き換えたバイオームや標高も反映されます（セルの形と隣の関係は書き換えられません）

操作：左ドラッグで回す、右ドラッグで動かす、ホイールで寄る、クリックでセルを選ぶ。

## URL のパラメータ

今の設定は URL に残ります。そのまま共有すると、同じ地図が開きます。

| パラメータ | 意味 |
|---|---|
| `combo` | 形（0 平面・矩形、1 平面・ヘクス、2 円筒・矩形、3 円筒・ヘクス、4 球・ヘクス） |
| `seed` | シード（0〜4294967295） |
| `w`、`h` | 幅と高さ（平面・円筒） |
| `m` | 分割数（球） |
| `scale` | 標高の倍率（0〜30） |
| `wrap` | `1` で円筒を巻いて表示する |
| `select` | 選ぶセルの番号 |
| `yaw` | カメラを回す角度（度） |
